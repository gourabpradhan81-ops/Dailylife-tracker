# Dailylife-tracker

built with Python to record, analyze, and visualize daily habits and activities. The project uses **NumPy, Pandas, Matplotlib, Seaborn, Plotly, and Streamlit** to turn daily-life data into meaningful insights through an interactive dashboard.

## 🚀 Project Overview

The Daily Life Tracker helps users monitor important aspects of their daily routine, such as:

* 💤 Sleep hours
* 🏋️ Exercise/workout
* 📚 Study hours
* 💻 Work/productivity hours
* 💧 Water intake
* 🍎 Meals/calories
* 😊 Mood
* 📱 Screen time
* 📝 Daily activities

The collected data can be analyzed to identify patterns, measure productivity, and understand how different habits affect daily performance.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Daily-Life-Tracker.git
cd Daily-Life-Tracker
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The dashboard will open in your browser.
